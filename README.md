# Nexus

**Nexus** is a multiplayer launcher for **Dota 2: Dawn of War**, designed to make hosting and joining games easier.

## ✨ Features

- **P2P Multiplayer** — Creates a local Dota 2 Dedicated Server host, allowing other players to join and play together through peer-to-peer (P2P) networking.
- **Rank Restrictions** — Set minimum and maximum rank requirements when creating a lobby.
- **Player Profiles** — View your personal profile, rank, and score.
- **Match History** — Review your previous game records.
- **Flexible Hosting** — The host does not need to participate in the match. Once a game is running, the host can close Dota 2 without disconnecting other players, as long as Nexus remains running.

## 📋 Requirements

- Windows 10 or later (64-bit)
- Steam and Dota 2 installed
- A working internet connection

## 🚀 Getting Started

1. Download `nexus_setup.exe` from the [Latest Release](../../releases/latest).
2. Run the installer and follow the installation instructions.
3. Launch Nexus and follow the instructions to create or join a lobby.
4. Invite other players to join your game.

## 🌐 Network Requirements

For the best connection experience, the host's NAT type should preferably be **Full Cone NAT**.

Other NAT types may cause connection difficulties for some players when joining a game. If players have trouble connecting, the host may need to check their router settings or network configuration.

**Important:** The host must keep Nexus running while hosting a game. Closing Dota 2 after the match starts will not disconnect other players, but closing Nexus may interrupt the session.
